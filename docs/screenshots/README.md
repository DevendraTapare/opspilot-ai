# Screenshot provenance

Screenshots are direct captures from actual Chromium against an isolated local
PostgreSQL, simulator, MCP and dashboard stack. They contain fictional service
data, a deterministic fixture investigation and a synthetic authenticated operator.
They are not mockups, generated artwork or evidence of real LLM reasoning.

| File | View |
|---|---|
| healthy.png | Three services with actual healthy workload observations |
| investigation.png | Fixture graph progress, real MCP calls and cited evidence |
| approval.png | Exact sandbox action and target before approval |
| recovery.png | Persisted verified recovery and audit timeline |
| evaluations.png | Historical benchmark with unavailable model arms and visible gates |
| architecture.png | Implemented workflow and MCP inventory |
| mobile.png | Responsive live incident list |

`provenance.json` records the browser runs, successful capture tests, source names and
SHA-256 hashes. Credentials/login entry were not captured. Images were visually
inspected before publication. Raw browser results and attachments remain private
in the unique `artifacts/stage8/` run directory; older captures were not overwritten.
